## Contexto

Green Jurisdictions Database es una plataforma de datos ambientales de Earth Innovation Institute. La experiencia pública permite descubrir jurisdicciones y explorar información ambiental. Tropical Fire Observatory es otra superficie del mismo proyecto, con dominio propio e interfaz cartográfica.

## Mi contribución

Como desarrollador full-stack, trabajé en mapas interactivos, búsqueda y exportación de datos. Mis responsabilidades incluyeron funcionalidades frontend, APIs en Laravel, desarrollo con Docker y flujos de GitHub Actions.

Mi contribución fue parte de un esfuerzo de equipo. Las capturas públicas muestran el contexto del producto, no propiedad individual de toda la interfaz o del conjunto de datos.

## Alcance de ingeniería

El stack combinó Next.js y React en el frontend, APIs en Laravel y PostgreSQL. El trabajo cruzó el límite entre encontrar información en una interfaz y ofrecerla mediante servicios backend y exportaciones.

## Dos experiencias conectadas

La base de datos permite descubrir jurisdicciones y cultivos. Tropical Fire Observatory presenta información de incendios geográficamente. Las dos capturas muestran experiencias distintas dentro del mismo proyecto.
